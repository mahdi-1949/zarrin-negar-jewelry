# زرین‌نگار | فروشگاه طلا

وب‌سایت فارسی و راست‌چین فروشگاه زرین‌نگار؛ ساخته‌شده با HTML، CSS و JavaScript و آماده انتشار در GitHub Pages.

## صفحات

- صفحه اصلی و فروشگاه
- جزئیات محصول و سبد خرید
- داستان برند و تماس با ما
- مجله، مقاله، پرسش‌های متداول و راهنمای ارسال

## انتشار

با هر تغییر در شاخه `main`، گردش‌کار GitHub Actions فایل‌های سایت را در GitHub Pages منتشر می‌کند.
